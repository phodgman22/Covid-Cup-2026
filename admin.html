Event

Allowance applies to every player's course handicap, which the app calculates from the tee's rating and slope. A player can override the percentage on his own row below.

Team handicap weightings

For the formats that play one ball per team. Each row is a group size, and the boxes run from the lowest handicap in the group to the highest — so “35 / 15” means 35% of the low man plus 15% of the high man.

Only used by Scramble and Alternate shot. Every other format uses each player's own handicap, so there's nothing to weight. Group sizes above four fall back to an even split.

Spreadsheet setup

Faster than typing 18 holes by hand. Download the template, fill it in Excel, and upload it back — courses, tees and players all come in at once.

The download includes whatever you've already entered, so it works as an export too. Uploading replaces courses and players. Players are matched by name — anyone already in the roster keeps their existing login code.

Courses

Add every course the event plays. Rounds point at one of these.

Players

Tees are matched by name across courses, so use the same tee name (e.g. “White”) on every course a player plays from.

Rounds

Each round has its own course and format. Scores carry across every round onto one leaderboard.

Groups

Build groups of any size — twosomes, threesomes, foursomes, whatever the round needs. Groups are set per round, so pairings can change day to day.
